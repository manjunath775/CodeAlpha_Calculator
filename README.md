# 🧮 Calculator

A simple and responsive calculator built using **HTML, CSS, and JavaScript**


## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔄 Clear button
* ⌫ Delete button
* 🔢 Decimal number support
* ⌨️ Keyboard support
* ⚡ Real-time display
* 🎨 Hover effects and animations
* 📱 Responsive design
* ⚠️ Division-by-zero error handling

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Netlify

## 📂 Project Structure

```text
Calculator/
├── index.html
├── style.css
└── script.js
```

## ⌨️ Keyboard Controls

| Key         | Action         |
| ----------- | -------------- |
| `0-9`       | Enter numbers  |
| `+`         | Addition       |
| `-`         | Subtraction    |
| `*`         | Multiplication |
| `/`         | Division       |
| `Enter`     | Calculate      |
| `Backspace` | Delete         |
| `Escape`    | Clear          |

## 🚀 How to Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
